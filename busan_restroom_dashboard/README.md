# 부산역 CCTV 대시보드

## 실행

```bash
cd ~/Downloads/cctv032/busan_restroom_dashboard
../.venv-cctv/bin/python -m streamlit run app.py
```

메인 상단에서 CCTV 세 곳을 순차 분석합니다. 원본 영상과 yolo11n.pt는 기존 맥북 파일을 사용합니다.
북쪽/동쪽/남쪽 이름의 영상은 앱 폴더와 바로 위 cctv032 폴더에서 자동 탐색합니다.

## 재생 연동

메인·화장실 상세·사이니지는 같은 브라우저, 같은 앱 주소에서 재생 위치와 재생/정지 상태를 공유합니다.
메뉴를 바꿀 때 마지막 재생 위치를 이어받고, 자동 재생이 허용되면 이어서 재생합니다.
다른 페이지에서 재생/탐색을 조작하면 현재 표시 중인 페이지도 그 상태를 받습니다.
시각은 영상 currentTime 기준이며 14:00:00부터 표시합니다. 영상이 멈추면 사이니지 시각도 멈춥니다.
새 분석 작업에서는 별도의 재생 상태를 사용합니다. 브라우저 저장소를 지우면 기억한 재생 위치도 초기화됩니다.

사이니지는 재생 시점의 실제 분석 집계로 색상·대기시간·추천 경로를 갱신합니다.
세 원본 영상의 0초가 같은 시연 시점이라는 전제입니다. 공통 재생 길이는 가장 짧은 영상 기준입니다.
내부 잔류·대기시간은 모듈의 초기 인원·칸수·평균 이용시간 가정에 따른 추정입니다.
실제 예측모델이나 실시간 카메라 스트림은 연결되지 않았습니다.

## 날짜별 기록

엑셀의 1분 모의 기록으로 대기인원/추정 대기시간 그래프를 표시합니다.
그래프 아래의 ‹ 날짜 ›로 날짜를 넘기고 숫자 날짜를 누르면 달력을 엽니다.
별도 시각 입력칸과 선택 시각 카드 3개는 제거했습니다. 그래프의 툴팁으로 시각별 값을 확인합니다.
TOILET_A=북쪽, B=동쪽, C=남쪽. 원본 엑셀은 assets/restroom_usage.xlsx에 보존되어 있습니다.
대기시간 열이 없어 대기 0명은 0초, 대기 시 (Q+1)*평균 이용시간/운영칸수로 추정합니다.
모의 엑셀 기록은 CCTV 영상 분석 기록과 별개이며 시각별 대기인원을 합산하지 않습니다.

## 보관 및 진단

영상/모델 경로와 설정은 data/settings.json, 분석 기록은 data/dashboard.sqlite와 실행별 data/<ID>/에 보관됩니다.
업데이트 설치는 영상과 data/를 유지하고 변경 전 코드를 .updates/에 백업합니다.
MOV/HEVC가 재생되지 않으면 시연 설정의 미리보기 MP4 변환을 사용하세요.

실제 영상 추론은 사용자 맥에서 확인해야 합니다. 이 업데이트는 UI·날짜 선택과 공유 재생 로직을 검사했습니다.
분석 모듈: https://github.com/IRE0330/2026DeepLearning-1/releases/tag/cctv-analysis-v0.3.2
