대기거리 구간 표시 수정

원본 거리구간 컬럼(예: 마지막대기자_거리구간) 또는 대기거리구간_예측단계를 선택하세요.
5m - 10m 같은 텍스트도 인식합니다. 표·CSV·엑셀에 거리 구간을 표시합니다.
0=대기 없음, 1=5m 미만, 2=5m 이상 10m 미만, 3=10m 이상 15m 미만, 4=15m 이상.
기존 미래 예측은 순서형 숫자 예측을 유지하며 가장 가까운 단계로 표시합니다. 분류 확률을 출력하는 분류 모델은 아닙니다.
압축 해제 후 기존 가상환경을 사용해 python -m streamlit run app.py --theme.base light 실행.
기존 결과를 사용 중이면 타깃을 다시 선택하고 예측을 다시 실행하세요.

예상 대기시간 (거리 환산) 열 추가: 대기 없음=0분 / 5m 미만=5분 미만 / 5~10m=5분 이상 / 10~15m=10분 이상 / 15m 이상=15분 이상. 프로젝트 환산 기준이며 실제 측정 시간이 아닙니다.
