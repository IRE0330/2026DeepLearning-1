# 0.3.2 배포 자료·라이선스 고지

확인일: 2026-10-21. 분석·마스킹은 검증된 0.3.2이며 오늘의 구역 실험·수동 정답·정확도 실험 결과를 포함하지 않는다.

## YOLO11n 가중치

Ultralytics YOLO11n COCO 사전학습 모델 `yolo11n.pt`를 사용한다. [공식 v8.3.0 파일](https://github.com/ultralytics/assets/releases/download/v8.3.0/yolo11n.pt)을 새로 다운로드해 팀의 실제 사용 파일과 SHA-256이 동일함을 확인했다.

`0ebbc80d4a7680d14987a577cd21342b65ecfd94632bd9a8da63ae6417644ee1`

[공식 라이선스 설명](https://www.ultralytics.com/license) 및 [AGPL-3.0 조건](https://www.ultralytics.com/legal/agpl-3-0-software-license)은 소프트웨어·모델의 AGPL-3.0 공개 조건과 Enterprise 대안을 설명한다. AGPL 경로의 재배포에는 해당 라이선스/저작권 고지 보존 및 대응 소스 제공 등의 의무가 있으며, 더 큰 결합 프로젝트에도 공개 조건이 적용될 수 있다. 비공개/상용 연동은 해당 조건 또는 Enterprise 권한을 별도로 확인해야 한다.

이 저장소는 프로젝트 전체의 배포 라이선스를 별도로 확정하지 않았으며, 이 문서가 다른 팀원 코드의 라이선스를 정하거나 새로운 권리를 부여하지 않는다. 따라서 **가중치를 이 Release에 직접 재첨부하지 않고**, 같은 파일의 공식 다운로드 경로·파일명·해시·설치 명령을 제공한다. README의 명시적인 `python -m cctv download-model`과 `diagnose_install.py --model`로 다운로드/검증한다. 분석 중 자동 다운로드는 하지 않는다. 이 배포가 결합 애플리케이션 전체의 라이선스 준수를 보증하지는 않는다.

## 영상과 결과

- 기존 원본 3개와 결과 영상: 공개 공유 권한의 명시적 근거를 확인하지 못해 게시하지 않는다. 파일이 로컬에 있다는 사실이나 synthetic_material 태그를 권한의 증거로 보지 않는다. 사용 권한이 있는 팀원 간 별도 전달이 필요하다.
- 전체 outputs/final 및 evidence/history: 영상·진단·개인 PC 실행 경로가 섞여 있어 통째로 게시하지 않는다.
- 공개 가능한 최종 예시 CSV 3개: 기존에 공유용으로 지정된 `examples/data/{north,south,east}_2026-10-14_0000.csv`만 게시한다. 공유 정본과 바이트가 같은지 검사한다. 기존 안정 결과를 보존하며 오늘의 실험 결과나 수동 정답을 넣지 않는다.
- MICC: 사용자 확인에 따라 데이터/아카이브/결과는 제외한다. 검증된 0.3.2 안의 목록 점검 보조 코드와 테스트는 유지한다. 모델 학습이나 MICC 자료의 공개 권한을 주장하지 않는다.
- 인증정보·가상환경·임시 로그·로컬 설정·원본 미디어는 Release/ZIP/Git 스테이징 대상이 아니다.

가중치·의존성·원본이 없으면 새 실제 분석은 실패해야 한다. 기존 예시 CSV를 읽어 분석 성공으로 대체하지 않는다. 각 의존성의 고유 라이선스도 설치 환경에서 보존해야 한다.
