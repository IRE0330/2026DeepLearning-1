## 적용 기준과 미리보기

## 전체 검증과 실제 사람 유지

0.3.0 동쪽 전체 로그의 프레임 시각·추적 ID·박스를 재사용했습니다. 재추론·재추적 없이 전체 상태를 재계산하고 원본 해시를 확인한 영상 전 프레임을 새 구역과 수치로 렌더링했습니다. 기존 결과는 보존했습니다.

소화기 오탐 ID는 10/25/37/127/134/179/221/354/386/388이며 원본 대표 장면으로 확인했습니다. 총 1,847개 관측 중 기존 구역에서 제외되던 433개는 그대로, 나머지 1,414개는 새 구역에서 제외됐습니다. 기존 confirmed 관측은 405개였고 새 실행에서는 소화기의 confirmed 및 가림 유예가 **모든 프레임에서 0**입니다. 소화기 이외 관측은 기존 `observation`/`excluded_observation` 구분과 대기 상태가 전 프레임 그대로임을 비교했습니다.

주변 실제 ID 1/2/26/192/246은 새 구역 때문에 추가 제외되지 않았습니다. ID 2의 관측 266개와 후보 141프레임, ID 246의 관측 77개와 후보 35프레임도 동일합니다. ID 2에서 원래 다른 제외 구역에 걸리던 2개 관측은 그대로이며 이번 구역 때문에 생긴 손실이 아닙니다. 출입 events.csv는 바이트 동일하며 입장/퇴장 5/3, 최종 내부 5명도 유지됐습니다.

이 영상에는 주변 실제 사람이 3.5초를 충족해 confirmed가 되는 사례가 없습니다. 실제 대기자의 양성 집계는 영상으로 검증하지 못했습니다. 대신 실제 ID 2의 박스(새 다각형과 겹치지만 발은 밖)를 고정한 모델 없는 테스트에서 3.5초 후 1명 확정·짧은 가림 1명 유지, 소화기 0명을 확인했습니다. 이미 확정된 소화기를 제외 관측으로 재관측하면 즉시 0명이며 이후 가림에도 남지 않는 테스트도 포함했습니다.

외부 대기 정수초 평균 0.178→0.000명, 최대 1→0명입니다. 이는 확인된 정적 오탐 제거 결과이며 전반적 정확도 개선의 수치로 해석하지 않습니다. 원래 실제 대기가 0명이었다는 정답 주장도 하지 않습니다.

테스트는 패키지 96개 중 95개 통과·Streamlit 선택 의존성 부재로 1개 건너뜀, 루트 호환 88개 모두 통과했습니다. 설치한 0.3.1 wheel의 공개 API로 동쪽 27–33초를 CPU에서 실제 재추론하여 6개 레코드를 받았습니다. 새 구역 내 관측 278개가 nonwaiting이며 수신 외부 대기 6개 모두 0, 수신 CSV·상세 상태·동일 관측 Counter 재계산값이 일치했습니다. 이 재추론은 설치 확인이며 전체 전후 비교의 동일 추적 입력을 대체하지 않습니다. 최종 wheel 소스·번들 58개 파일과 설치본의 바이트 일치도 검증했습니다.
