## 실제 명령과 적용 설정

프로젝트 최상위 PowerShell에서 실행한 분석 명령입니다. 시험 구간 제한을 지정하지 않았고 등록목록에도 `start_s`/`end_s` 제한이 없습니다.

```powershell
& .\.venv\Scripts\python.exe -B -u -m cctv batch --registry configs/video_registry.json --profile demo --device cpu
```

원본 경로/영상 ID/해시는 기존 등록과 일치했고 전체 PTS 검사에서 세 영상 모두 고정 FPS였습니다. 영상이 바뀔 때마다 기존 batch 코드가 Detector·ByteTrack·Counter를 새로 생성합니다. 공통 탐지·추적·출입/대기·계산·CSV 코드는 변경하지 않았습니다.
