ZIP 다운로드와 압축 해제가 끝났고 `data/micc/micc_crowd_counting`를 검사했습니다. 재다운로드·재압축해제는 하지 않았습니다. 이전 ZIP 중앙 디렉터리 오류 기록은 초기 다운로드 중의 이력으로 보존하며 현재 폴더 상태와 구분합니다. 이번 보고서는 `inspections/micc_20261014_112925_a7b18a08/micc_inventory.json`입니다.

RGB 샘플은 640×480, uint8 3채널 PNG, depth는 640×480 uint16 PNG입니다. 깊이 단위나 RGB 좌표 정합은 이 값만으로 확인하지 않았습니다. `.DS_Store`와 `._*`는 파일 수에서 제외했습니다. 숫자 범위 내부의 파일명 누락은 없습니다. 단, RGB 전체 3364장과 실제 GT 3358개는 차이가 있습니다. 동봉 readme의 “3364 annotated frames” 설명과 달리 Flow 마지막 6장에는 GT가 없어 미확인으로 기록합니다.

동봉 `readme.txt`, `evaluation_code/README.txt`, `precision_recall_by_dat.m`와 실제 비어 있지 않은 `.dat` 행을 확인했습니다. **머리 박스 `x_top_left y_top_left width height`**이며 전신 박스가 아닙니다. Flow `46.dat`의 첫 행은 `418 420 49 49`, Queue `1.dat`에는 8개 행, Groups `44.dat`에는 `268 417 49 49` 행이 있습니다. 모든 시퀀스 GT_dat의 비어 있지 않은 행은 4열입니다. 평가 코드는 머리 박스 행 수를 인원수로 사용합니다. 별도의 인원수 스칼라나 지속적인 추적 ID 열은 확인되지 않았습니다. `evaluation_code/GT/GT_*_dat`에는 0으로 채운 파일명의 GT 복사본이 있고, `RES/RES_*_dat`는 기존 평가 결과 입력 자료로 제공되며 사용자 정답으로 취급하지 않았습니다. 머리 GT와 전신 탐지 박스를 직접 매칭하지 않았습니다.

포함된 설명·MATLAB 코드에서 원본 FPS/타임스탬프를 찾지 못했습니다. PNG 파일 수정시각을 촬영시각으로 사용하지 않았습니다. 새 `micc-track`는 숫자 순서의 연속 PNG를 같은 YOLO11n → ByteTrack 코드로 처리하고, `source_frame_number`로만 기록합니다. 출입·대기·체류의 초 단위 규칙을 호출하지 않습니다. `preview.mp4`는 임의 12 FPS의 시각 점검용임을 영상과 summary에 표시합니다. 자동 정답 변환·추가 학습·MICC 정량 평가는 하지 않았습니다.

## 사용자 입력이 필요한 남은 작업

코드 점검 결과, 공통 탐지→ByteTrack→규칙→집계 구조와 환경 JSON 분리, person 클래스만 사용, 실행별 모델·추적·규칙 초기화, CFR 영상 시각 기준 처리, 유한 경계·양쪽 확인·흔들림 중복 방지·실제 재입장, 짧은 전진 유지, 관측/유예 대기 분리, 다른 ID 병합 없음, null/0 구분, 음수 원시 값과 이상 로그, 초기값+출입 차이로 내부 인원 계산, 평균 이용시간 자동 차감 없음, 실행별 고유 결과 폴더, 빈 정답에 지표 생성 금지를 확인했습니다. 내부 인원은 변기 칸 점유 수가 아닙니다. 수정한 결함은 짧은 관측 유실의 출입 경로 연결·대기 후보 증거 유지와 경계 연장선만 가로지르는 화살표 허용입니다. 이 점검은 코드와 모의 테스트의 범위이며 실제 카운팅 정확도는 구역/정답 확인 뒤 검증합니다.

`docs/continuation_checks.json`: 기존 설정·정답 19개 파일의 SHA-256 동일 확인, 기존 baseline 4개와 새 east baseline의 결과 파일 존재 및 출입/시계열 CSV 헤더 전용 확인, 새 MICC 4개 실행의 완료/출력 검증 기록. ZIP 중앙 디렉터리도 현재 정상적으로 읽었습니다(전체 CRC 검사는 하지 않음). `doctor`의 재실행에서 auto=cpu, CUDA=false, MPS=false를 확인했습니다.

- **사용자 마우스 구역 확정:** north는 사용자 저장과 미리보기 확인을 받았습니다. south·east는 미확정입니다. 이 에이전트가 사용자 구역을 자동 지정하지 않았습니다.
- **실제 CCTV 카운팅 검증:** north 0~10초 집계 분석은 실행됐지만 최신 결과의 입장/퇴장은 0건이며 아래 ID 6 실패 사례를 조사했습니다. 설정·추적의 실제 정확도 검증은 미완료입니다. south·east 집계는 미실행입니다. 모의 테스트로 실제 정확도를 주장하지 않습니다.
- **수동 정답 평가:** 실제 양식은 헤더만 있습니다. 설명용 예시는 별도 폴더이며 평가에서 거부합니다. Precision/Recall/F1/MAE 실측값은 없습니다.
- **일반화 평가:** 세 화장실 영상은 개발 자료입니다. 별도 미사용 영상 검증이 없습니다.
- **CUDA/MPS 실제 추론:** CPU 빌드로만 검증했습니다.
