새 탐지·ByteTrack 추적을 실행하지 않습니다. `diagnostics.jsonl`의 매 프레임 `observation`/`excluded_observation`으로 확정 ID·박스·신뢰도를 복원하고, 변경하지 않은 `Counter`에 같은 순서로 재생해 상태를 복원합니다. 이 과정에서 생성되는 **모든 프레임 진단 전체**, CSV의 **전체 출입 이벤트**, **모든 정기 기록 상태·최종 상태·이상 집계**가 원 실행과 같아야 통과합니다. 값이 다르면 오류로 중단하며 일치한다고 보고하지 않습니다. CSV를 새로 쓰지 않습니다.

영상 배경은 원본 `북쪽_화장실_cctv.mp4`, `남쪽 화장실_CCTV.mov`, `동쪽_화장실_cctv.mov`에서 읽고 원본 해시를 확인합니다. 기존 `annotated.mp4` 위에 덧씌우지 않으므로 예전 상단 패널이 가리던 원본 화면도 새 출력에서는 다시 표시됩니다. 저장된 추적 결과를 재생하는 표시 작업이며 새 사람 탐지나 카운팅 정확도 평가가 아닙니다.
