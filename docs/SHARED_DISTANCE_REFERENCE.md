# 공통 CCTV 거리 기준선

`configs/distance_reference.json`은 북쪽·동쪽·남쪽의 시작점과 5m·10m·15m 선 양 끝점을 보관한다. 좌표는 영상 전체 프레임의 정규화된 `(x, y)`이며 왼쪽 위는 `(0, 0)`, 오른쪽 아래는 `(1, 1)`이다. JSON에는 저장된 원래 정밀도의 좌표가 들어 있다.

팀원은 수정된 대시보드 코드와 이 공통 JSON을 함께 사용하고, 기존 영상 연결 화면에서 각 방향에 해당하는 원본을 연결하면 된다. 각 PC의 `data/settings.json`을 공유하거나 바꿀 필요가 없다. 원본 영상의 파일 내용 SHA-256이 일치하면 경로·파일명·수정 시각과 관계없이 공통 좌표를 자동 적용한다. 재인코딩·편집한 영상은 바이트가 달라 자동 적용하지 않는다. 임의의 다른 영상이나 다른 방향의 영상을 대신 연결해도 공통 기준선을 적용하지 않는다.

이 설정은 실제 미터 단위 보정이나 실제 대기시간 측정값이 아니다. 기존의 **임의 거리 기준 시연값**, 후보자 포함 조건, 판정 알고리즘 및 3초 안정화 정책을 그대로 사용한다.

## 기존 기록과의 연결

공통 파일의 `legacy_source_keys`는 내보낼 때 동일 원본과 일치함을 확인한 이전 키다. 기존 기록의 키를 무조건 무시하지 않는다. 새 분석 요청에는 원본의 SHA-256도 함께 저장하므로 나중에 다른 PC로 옮긴 경우에도 영상과 기록의 연결을 검사할 수 있다. 확인되지 않은 이전 키만 있는 분석은 임의로 공통 기준선에 연결하지 않는다. 좌표가 없는 옛 분석 기록에서 인원 수를 이용해 거리 결과를 만들어내지 않는다.

화면용 설정에는 실제 재생에 선택된 원본을 전달하므로, 분석 요청의 이전 PC 경로가 사라져 현재 PC의 동일 원본을 대신 재생하는 경우도 검사한다. 기존 DB와 기록은 다시 쓰지 않는다.

## 편집 화면과 표시

공통 JSON의 `hide_editor`가 `true`이고 세 CCTV의 원본·분석 연결이 모두 검증된 경우에만 시작점·기준선 편집 컨트롤을 숨긴다. 기존 안내와 기준 표, 영상 위의 기준선 오버레이는 유지한다. 다른 영상이나 누락된 영상이 있으면 검증 완료로 간주하지 않고 기존 편집 기능을 유지한다.

향후 기준선을 다시 편집해야 하면 이 공통 파일의 `hide_editor`를 `false`로 설정해 기존 편집 화면을 사용한다. 새 기준선을 배포할 때는 로컬 저장 좌표와 원본의 일치를 다시 검증해서 공통 JSON을 새로 만든다. 내보내기는 기존 파일을 덮어쓰지 않는다.

```powershell
python scripts/export_distance_reference.py --output configs/distance_reference.next.json
```

내보낸 파일은 편집기를 숨기지 않는 상태(`hide_editor: false`)로 생성된다. 실제 원본의 다른 경로 복사본·기존 기록·오버레이를 검증한 다음에만 `hide_editor`를 활성화한다. 원본 영상·모델·설정·DB·분석 산출물은 공통 파일에 포함하지 않는다.

## 자동 테스트

```powershell
python -m unittest discover -s tests -p test_distance_reference.py
```

테스트는 다른 PC를 나타내는 별도 경로에 파일명·수정 시각이 다른 동일 바이트의 파일을 만들고 자동 적용, 방향별 격리, 다른 내용 거부, 과거 키 호환, 새 분석의 원본 해시, 잘못된 설정의 안전한 처리, 편집 UI 숨김, 오버레이 유지를 검증한다.
